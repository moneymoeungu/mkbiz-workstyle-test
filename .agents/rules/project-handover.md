# 매경비즈 직장인 성향 테스트 (.xlsx 테마) — 프로젝트 인수인계 컨텍스트

이 워크스페이스는 `매경비즈 직장인 성향 테스트 PRD.md`를 기반으로 구축된 웹 애플리케이션입니다. 다른 디바이스에서 작업을 이어갈 때 아래 결정 사항과 히스토리를 반드시 유지하세요.

## 1. 파일 구조
- `index.html`: 엑셀(Excel) 윈도우 타이틀 바, 수식 입력줄(`fx`), 열 머리글(`◢ | A | B | C | D`), 메인 스테이지, 하단 시트 탭 바(`사원등록_홈`, `내결과_사원증`, `16유형_전체시트`, `AX_익명통계`) 레이아웃
- `css/styles.css`: 엑셀 스프레드시트 UI/UX 디자인 시스템 (Excel Green `#1D6F42`, 모눈종이 셀 그리드 배경, 초록색 활성 셀 테두리 & 우측 하단 자동채우기 사각 핸들, 한국어 어절 줄바꿈 `word-break: keep-all`)
- `js/data.js`: 4축(`tempo`, `decision`, `collab`, `crisis`) 정의, **15개 핵심 문항(직장인 현실 업무·고민 반영, Q12~Q15 가중치 1.5 적용으로 동점 방지)** + 파일럿 예비 8문항, 16유형 상세 데이터(유형별 `animal`, `outfitLabel` 포함), 궁합 등급(0~100점 및 데칼코마니 50점), 금칙어 필터
- `js/pixelArt.js`: 16유형별 고유 **귀여운 직장인 동물 캐릭터** 캔버스 일러스트 엔진 (호랑이, 사자, 강아지, 판다, 토끼, 사슴, 원숭이, 양, 곰돌이, 고양이, 펭귄, 개구리, 꼬꼬, 여우, 아기돼지, 병아리 + 양복/넥타이/커리어 우먼 안경/블레이저/사원증/업무 소품)
- `js/cardExporter.js`: 1:1 (`1080x1080`) 및 9:16 스토리용 (`1080x1920`) 고해상도 PNG 사원증/궁합 카드 생성기 (한글 어절 단위 자동 줄바꿈 `drawWrappedKoreanText` 적용)
- `js/analytics.js`: 개인 식별 정보(실명·닉네임·부서)를 제외하고 수집하는 익명 KPI 이벤트 로거 및 5명 미만 표본 마스킹(`< 5명`) 집계 모듈
- `js/app.js`: 원스텝 홈 화면(닉네임 즉시 입력 후 1번 문항 진입), 15문항 퀴즈, 로딩, 결과 사원증, 동료 궁합(`VLOOKUP`), 16유형 도감 모달, AX TF 통계 모달 컨트롤러

## 2. 핵심 디자인 & UX 원칙 (사용자 피드백 반영 완료)
1. **엑셀(Excel) 표 컨셉의 직장인 바이브 UI/UX**:
   - 상단 녹색 엑셀 타이틀 바, 실시간으로 바뀌는 `fx` 수식 입력줄, 모눈종이 격자 배경, 조건부 서식 데이터 막대(Data Bar) 표 스타일을 유지할 것.
2. **직관적인 한국어 카피 & 줄바꿈**:
   - 홈 화면이나 캐릭터 카드에 일반 사용자가 이해하기 어려운 영문 약어(`SDLC`, `SILR` 등)를 전면에 노출하지 말 것.
   - 모든 텍스트는 `'나는 어떤 곰돌이/동물일까'`가 아니라 **'나의 직장인 성향 / 유형'**이 주제임 (캐릭터만 귀여운 직장인 동물 일러스트로 표현).
   - 한글 단어 중간이 끊어지지 않도록 `word-break: keep-all`을 엄격히 유지할 것.
3. **수동 의상 선택 제거 & 유형별 맞춤 코디 강조**:
   - 별도의 의상 선택 버튼을 두지 않고, 16개 직장인 유형마다 고유한 동물 + 의상(정장, 넥타이, 커리어 우먼 안경, 가디건 등) + 소품 조합이 자동으로 강조되도록 유지할 것.
4. **홈 화면 원스텝 시작 & 개인 이름 미노출**:
   - 홈 화면에서 바로 닉네임을 입력하고 시작 버튼을 누르면 1번 문항으로 즉시 진입함.
   - 닉네임 입력창 placeholder에 특정 개인 실명('채린' 등)을 넣지 말 것.
