# 매경비즈 직장인 성향 테스트 (`mkbiz-workstyle-test`)

매경비즈 구성원의 소통과 협업을 위한 **직장인 성향 테스트 & 동료 업무 궁합 웹 애플리케이션**입니다.

## 주요 특징
- **엑셀(Excel) 스프레드시트 오피스 UI/UX**: 직장인에게 친숙한 엑셀 타이틀 바(`#1D6F42`), 실시간 수식 입력줄(`fx`), 모눈종이 셀 그리드, 조건부 서식 데이터 막대(Data Bar), 하단 워크시트 탭 디자인
- **16종 직장인 동물 캐릭터 일러스트**: 16개 직장인 성향 유형마다 각기 다른 귀여운 동물(호랑이 대리, 사자 팀장, 토끼 프로, 판다 선임, 사슴 디렉터 등)과 맞춤형 오피스 착장(정장, 넥타이, 커리어 우먼 안경, 블레이저, 사원증) 및 시그니처 소품 자동 렌더링
- **사원증 이미지 저장 & 동료 궁합(`VLOOKUP`)**: 1:1 피드/메신저용(`1080×1080`) 및 9:16 스토리용(`1080×1920`) 고해상도 PNG 사원증 저장, 초대 링크 기반 동료 궁합 비교
- **익명 보장 & k-익명성(`k=5`) 통계**: 실명·사번·부서를 수집하지 않으며, 5명 미만 표본은 `< 5명`으로 마스킹 처리

## 다른 컴퓨터(디바이스)에서 Antigravity로 이어서 작업하는 방법

1. **새 컴퓨터에서 저장소 클론(Clone)**
   ```bash
   git clone https://github.com/moneymoeungu/mkbiz-workstyle-test.git
   cd mkbiz-workstyle-test
   ```
2. **Antigravity에서 폴더 열기**
   - Antigravity 실행 후 `File > Open Folder`로 클론한 `mkbiz-workstyle-test` 폴더를 엽니다.
3. **자동 컨텍스트 로드 (`.agents/rules/project-handover.md`)**
   - 프로젝트 내부의 `.agents/rules/project-handover.md` 파일에 지금까지의 모든 요구사항, 디자인 컨셉(엑셀 UI, 16종 동물 직장인 캐릭터, 한국어 줄바꿈 규칙 등)이 저장되어 있어, 새 컴퓨터에서 Antigravity에게 바로 다음 작업을 지시하셔도 이전 맥락을 100% 이해하고 이어서 작업합니다.
4. **로컬 실행 확인**
   - 별도의 빌드 과정 없이 `index.html`을 브라우저로 열거나 Live Server / `npx serve .`로 즉시 실행할 수 있습니다.
